Read the guide How it works

It adopts what it did not start

Almost every other tool is a launcher, and cannot see a session you opened by hand. clownhead reads Claude Code's own state, so the herd it shows is whatever is already running.

Readable from the tab bar

Every reload tints each session's iTerm2 tab to match its state, so a board you are nowhere near still tells you who is waiting. clownhead paint does it without the board at all.

Finds the work behind a pull request

Nothing on a session records which pull request it belongs to. Paste the URL into the filter and clownhead reads the transcripts until it finds the sessions that worked on it.
